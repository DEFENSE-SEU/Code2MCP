## 🔴 专家级测试（复杂工作流）

### 11. 完整地震分析流程
```
帮我分析一次地震：
1. 查询 2024 年 1 月 1 日日本附近震级大于 5.0 的地震
2. 选择最大的一次地震
3. 下载该地震时刻附近台站的波形数据
4. 对波形进行去趋势和带通滤波（0.5-10 Hz）
5. 计算从震源到台站的 P 波和 S 波理论走时
6. 绘制滤波后的波形图
```
**预期结果**：完整的分析报告，包含事件信息、波形处理结果、走时计算和可视化图片

### 12. 震源机制可视化
```
绘制一个震源机制沙滩球，走向 45°，倾角 60°，滑动角 90°，保存为 beachball.png
```
**预期结果**：返回沙滩球图片路径

### 13. 互相关分析
```
计算两个波形文件 trace1.mseed 和 trace2.mseed 的互相关，找出它们之间的时间延迟
```
**预期结果**：返回最大相关系数、时间延迟（秒）

### 14. 多台站数据合并
```
合并以下三个波形文件：station1.mseed, station2.mseed, station3.mseed，保存为 merged.mseed
```
**预期结果**：返回合并后的道数和输出文件路径

### 15. 去仪器响应
```
从波形文件 raw.mseed 中去除仪器响应，使用台站元数据文件 inventory.xml，输出速度波形，保存为 corrected.mseed
```
**预期结果**：返回去响应后的波形信息
